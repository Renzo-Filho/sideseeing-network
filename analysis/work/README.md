# Working data — supporting material, not final results

For analysis-ready attributes, use [results/SP](../results/SP/README.md).

| Folder | Meaning |
|---|---|
| [prepared](prepared/README.md) | Validated, standardized source tables produced before attribute construction; about 2.7 GB |
| [evidence](evidence/README.md) | Historical source audits and the experiments supporting accepted M2/M6/U2 choices |
| [runs](runs/README.md) | Execution checkpoints, intermediate spatial calculations, manifests and logs |
| [organization_manifest.json](organization_manifest.json) | Exact old/new folder mapping and byte-preservation checks for this reorganization |

These datasets preserve lineage and allow another agent to reproduce or investigate results. They are not redundant exports to delete. Existing versioned configs intentionally retain old paths, which resolve through compatibility links. No source definitions, feature values or accepted decisions changed during organization.
